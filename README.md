# ChatHeal — Luxury Admin Studio

A clinical practitioner and coach workspace with frosted glass surfaces, colour-coded Lucide icons, responsive layouts, package management studio, and persistent light/dark themes.

## Features & Modules

- **Package Studio (`/packages`)**: Manage care packages (Yearly ₹20,000, 6-Month ₹12,000, Per Month ₹3,000), add new packages, edit pricing/duration, delete, duplicate, and toggle active/draft status.
- **Client Management (`/clients`)**: Review client profiles, adjust daily caloric targets, and monitor personalized nutritional care.
- **Content Library (`/discover`)**: Evidence-based nutrition guides, interactive dynamic wellness wheel, movement rituals, and blueprints.
- **Appointments (`/appointments`)**: Manage booking slots, upcoming consultations, and clinical calendar.
- **Live Sessions (`/sessions`)**: Telehealth diagnostics, video consultations, and client communication.
- **Nutrition Insights (`/progress`)**: Caloric intake logs, macronutrient distribution, and longitudinal adherence telemetry.
- **Practice Settings (`/settings`)**: Practitioner credentials, practice profile, security, and preferences.

## Run Locally

Use Node.js 20 or newer. From this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3002](http://localhost:3002).

## Production Build

```bash
npm run build
npm start
```
